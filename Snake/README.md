# Snake Game

A React + TypeScript snake game built with Vite.

## Setup

1. Install Node.js from https://nodejs.org.
2. Open the `d:\Github\Snake` folder in your terminal.
3. Run:

```bash
npm install
npm run dev
```

## How to play

- Use the arrow keys to move the snake.
- Eat the red food to grow and score points.
- Avoid running into your own tail.

The app uses Vite hot reload, so changes in `src/` are reflected automatically in the browser.
