Nebula Console — créditos / credits
====================================

3D engine
- three.js r162 (MIT License) — https://threejs.org  (vendored: vendor/three.module.js, GLTFLoader.js, BufferGeometryUtils.js)

3D environment / reflections
- RoomEnvironment (three.js examples, MIT) — procedural studio env map (vendor/RoomEnvironment.js)
  for PBR reflections/lighting on the pets. No external HDRI downloaded.

3D animal mascots (all original procedural three.js by KMM — no external/paid assets)
- Dog mascot: a procedural German Shepherd (black-&-tan coat with saddle, upright triangular
  ears, long black muzzle, wet eyes, bushy tail). No assets copied from any game.
  (No license-clear free CC0/CC-BY rigged German Shepherd / realistic dog GLB was available;
  all found were paid. The earlier CC0 "Fox" GLB is still vendored at vendor/Fox.glb but is no
  longer loaded — the dog is now the procedural shepherd. Fox: model © PixelMannen CC0,
  anim © tomkranis CC-BY 4.0, Khronos glTF-Sample-Assets, if ever re-enabled.)
- Rabbit mascot: a procedural realistic rabbit (natural agouti brown/grey/white coat variants,
  darker back + lighter belly, dark-tipped ears, pink inner ears, dark nose, wet eyes, whiskers).
  (No license-clear free CC0/CC-BY rigged rabbit GLB was available; all found were paid.)

Room + space backgrounds: original procedural three.js scenes by KMM.

Free games embedded in the library (each loads from its own site; credited in-app):
- Clumsy Bird — Ellison Leão (MIT)
- Astray 3D — wwwtyro (MIT)
- T-Rex Runner — wayou (MIT)

Everything else (UI, TV/console, carousel, voice, i18n, etc.) is original work by KMM.

A verified-CC0 animated cat glTF could be dropped into vendor/ and wired through the same
GLTFLoader path (tv3d.js: loadDogModel) to make the cat a rigged model too.
